# 📐 Geometry Library (ISRPO Lab)

> Учебный проект по дисциплине «ИСРПО» — модульная библиотека на языке Python для вычисления геометрических характеристик плоских и объемных фигур с покрытием модульными тестами.

---

## 📂 Структура проекта

Проект организован в виде модульной структуры, где каждая фигура вынесена в отдельный файл:

```text
isrpo_geometry/
│
├── src/
│   ├── __init__.py          # Инициализация пакета
│   ├── rectangle.py         # Прямоугольник (площадь, периметр)
│   ├── circle.py            # Круг (площадь, длина окружности)
│   ├── triangle.py          # Треугольник (формула Герона, периметр)
│   ├── trapezoid.py         # Трапеция (площадь, периметр)
│   └── sphere.py            # Сфера (объем, площадь поверхности)
│
├── main.py                  # Демонстрационный скрипт
└── test_geometry.py         # Модульные тесты (unittest)
🧮 ФункциональностьБиблиотека позволяет вычислять следующие параметры:Прямоугольник: площадь и периметр.Круг: площадь и длина окружности.Треугольник: площадь по формуле Герона и периметр (с проверкой существования сторон).Трапеция: площадь и периметр.Сфера: объем и площадь поверхности.🚀 Начало работыТребованияPython 3.8 или выше.Установка и клонированиеКлонируйте репозиторий на локальную машину


🧪 Тестирование В проекте реализованы unit-тесты с использованием встроенного фреймворка unittest. Тесты проверяют корректность вычислений, граничные значения (например, нулевые параметры) и обработку исключительных ситуаций.   Запуск тестов осуществляется следующей командой:Bashpython -m unittest test_geometry.py
